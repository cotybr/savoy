🔒 Aviso de Privacidade e Consentimento (LGPD)

Este assistente trata os seguintes dados pessoais, estritamente necessários:

  • Matrícula — identificação do colaborador;
  • Requisições de EPI — controle de segurança do trabalho;
  • Banco de horas — registro de jornada.

Os dados de sessão são armazenados localmente no navegador (sessionStorage) e as consultas trafegam por HTTPS até o Supabase, protegidas por políticas RLS.

Você pode revogar o consentimento a qualquer momento limpando os dados do navegador. A base legal é o consentimento (Art. 7º, I, LGPD).
